# 谁才是老登 - MVP PRD

## 1. 产品基础

* **产品名**：谁才是老登
* **副标题**：测测你们之间谁最有老登味
* **核心玩法**：自测 → 拉朋友进局 → 双人结果 → 三人局 → 分享
* **目标**：验证裂变链路，日活量可达到支持广告收益 5000/月

## 2. 六个核心维度

| 维度 | 前台展示 | 行为解释 |
| --- | --- | --- |
| 长辈感 | 长辈感 | 讲话带过来人味道 |
| 端着感 | 端着感 | 有架子，不太容易被反驳 |
| 懂王感 | 懂王感 | 什么事都能点评两句 |
| 冷场感 | 冷场感 | 容易把气氛拉回现实 |
| 资历感 | 资历感 | 喜欢用经历和经验压场 |
| 指挥感 | 指挥感 | 喜欢安排、主导、分配别人 |

## 3. 页面和流程

| 页面 | 功能 | 注意事项 |
| --- | --- | --- |
| 首页 | 产品介绍、开始按钮 | 强调老登味是“状态”，避免年龄攻击 |
| 答题页 | A/B/C 用户答题 | A 10题，B 8题，C 6-8题 |
| 半结果页 | 单人半结果、邀请好友 | 文案强调“需要对比才能定局”，制造未完成感 |
| 分享卡片 | 3 套（点名/对决/甩锅） | 便于裂变 |
| 好友进入页 | B/C 进入答题 | 强调“你来测，双方同时公开” |
| 双人结果页 | A/B 对比结果 | 最高维度类型 + 判词 + 再拉按钮 |
| 三人结果页 | 三人身份判定 | 每人身份，降低羞辱感 |
| 分享图生成 | 生成判定图 | 可附带激励视频广告 |

## 4. 数据结构

* **用户表**：user_id、昵称、头像、性别、注册时间、首次进入时间
* **题库表**：题号、维度、题干、4 个选项、分值映射、题类型（A/B/C）
* **答题记录表**：user_id、题号、选项、得分、时间戳
* **局表**：room_id、创建者、参与用户列表、状态、创建时间、完成时间
* **结果表**：room_id、用户老登浓度、六维得分、类型、判词、分享图路径
* **分享记录表**：room_id、发起用户、被分享用户、点击时间、是否完成测试
* **广告记录表**：user_id、广告类型、曝光/点击/收益、时间戳
* **埋点表**：事件名、用户 ID、时间戳、页面/操作、参数

## 5. 题库

* 总量：30 题，每维度 5 题
* 测试抽题：A 10题，B 8题，C 6-8题
* 每题 4 个选项，A/B/C/D → 0/1/2/3 分

## 6. 类型判定规则

* 每维度得分计算
* 老登浓度 = 六维平均
* 最高维度决定类型
* 并列优先级：指挥感 > 资历感 > 长辈感 > 懂王感 > 端着感 > 冷场感
* 老登等级分 8 档（0-15, 16-30,…,96-100）

## 7. 裂变设计

* 自证 → 点名 → 反击 → 甩锅 → 再拉人
* 第一版只做 1-3 人局
* 三人局简版降低羞辱感，增加裂变动力

## 8. 广告策略

* 可放：半结果页信息流、结果页信息流、生成分享图激励视频
* 不做：开屏、答题中途、好友进入页广告

## 9. 视觉风格

* 判定书 + 游戏局 + 轻复古感
* 活泼轻松色彩，避免低俗或攻击性
* 分享图风格统一，可截图传播

## 10. 冷启动计划

* 短视频矩阵、朋友圈/微信群、校园/公司群种子用户、公众号/私域引流
* 目标：第一周获取至少 1000 个种子用户完成测试

## 11. 合规检查

* 避免诱导分享和辱骂年龄群体
* 文案围绕“状态/味道”，不涉及身份攻击
* 数据收集符合平台隐私政策

## 12. 商业测算

* eCPM 10-20 元
* 日活 2000-4000，平均 2-3 次有效广告曝光
* 裂变链路必须维持 K≥0.3

## 13. 开发优先级

| 优先级 | 功能 |
| --- | --- |
| P0 | 首页、答题页、半结果页、好友进入页、双人结果页、分享图生成、题库/计分逻辑、数据埋点、广告预留 |
| P1 | 三人局入口/结果页、三套分享卡片、激励视频 |
| P2 | 多人榜、班级榜、公司榜、图鉴、长期档案、复杂排行榜 |

## 14. 数据指标

* 首页开始率 ≥30%
* A 完成率 ≥50%
* A 邀请率 ≥15%
* B 打开率 ≥20%
* B 完成率 ≥30%
* B 二次邀请率 ≥8%
* K 值 ≥0.3
* 止损规则：3-7天不达标先改文案/题目，再不行停掉

## 15. MVP 流程

1. A 自测 10题 → 半结果页 → 拉 B 进局
2. B 应战 8题 → 双人结果页 → 再拉 C（可选） → 三人局 6-8题 → 三人身份页
3. 分享图生成 → 分享 → 裂变传播

## 16. 最终目标

* 验证核心假设：用户愿意拉熟人进局，并继续拉下一人形成裂变闭环
* 通过数据判断裂变是否可持续，验证 MVP 成功可能性
