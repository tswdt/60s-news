# 谁才是老登 海报分享图设计稿（可直接制作）

## 通用设计建议

- 画布尺寸：1080×1920 px
- 主色调：活泼但不刺眼（如橙色/蓝色）
- LOGO 位置：顶部或居中偏上
- 核心判定文字：中间醒目
- 副文本：结论性话语
- 点缀图形：人物剪影、对话气泡、冲突感符号

## 模板 A — 对决型海报

**文件名建议**：`share_duel_{roomId}.png`

标题：

**系统说我俩之间必有一个老登**

核心内容区域：

**“{{A 用户名}}” vs “{{B 用户名}}”**

底部判词示例：

**TA 比我更老登？我不服！**

颜色：红 + 白

元素：对抗箭头、对决格斗背景

## 模板 B — 不服来测型

**文件名建议**：`share_challenge_{roomId}.png`

标题：

**谁才是老登？**

核心：空白头像或两个人剪影

文案：

**测完见分晓**

颜色：黄色 + 黑

元素：问号、冲突符号、对比条

## 模板 C — 甩锅继续邀请

**文件名建议**：`share_blowoff_{roomId}.png`

标题：

**本局老登还没定**

核心文本：

**差你一个，进来见分晓**

下方小字：

**三人局才知道真相**

颜色：蓝 + 白

元素：传递/邀请箭头、人物三角形

## 模板 D — 个性标签型

**文件名建议**：`share_tag_{roomId}.png`

标题：

**我测出老登味了**

标签区域，可循环列出：

- 长辈感拉满
- 指挥感强
- 懂王担当

副标题：

**你敢不敢和我一起来测？**

颜色：紫 + 白

元素：标签条、点赞气泡

## 视觉元素建议

- 背景图可用现实生活中“对话冲突”剪影
- 图中人物可用抽象卡通
- 判词使用对比颜色字体

这些模板既有冲突感，又不至于攻击性太强，适合裂变传播。
